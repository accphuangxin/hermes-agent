Welcome to Hermes Agent

This installer will set up Hermes Agent on your Mac. Hermes is a self-improving AI agent that creates skills from experience, improves them during use, and runs anywhere.

What will be installed:

  • A self-contained Python runtime at /usr/local/hermes/
  • The hermes, hermes-agent, and hermes-acp commands in /usr/local/bin/

Requirements:

  • macOS 13 (Ventura) or later
  • Apple Silicon (M1 / M2 / M3 / M4)
  • ~500 MB free disk space
